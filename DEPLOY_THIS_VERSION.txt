V8.7.0 RADAR PRO 배포 순서

1) Cloudflare Workers & Pages → btc-alt-scalper-v7 → Edit code
   worker/worker.js 를 새 파일로 교체 후 Deploy

2) GitHub Pages 저장소
   docs/index.html 교체/커밋
   (루트 index.html도 함께 동기화 권장)

3) 배포 후 브라우저 Ctrl+F5

4) 진단 주소
   https://<your-worker>.workers.dev/health
   https://<your-worker>.workers.dev/macro
   https://<your-worker>.workers.dev/altseason?part=live
   https://<your-worker>.workers.dev/altseason?part=hist

주의: 최초 역사 계산은 수초~수십초 걸릴 수 있으며 이후 KV/메모리 캐시로 빨라집니다.
