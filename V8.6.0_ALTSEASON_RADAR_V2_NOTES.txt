V8.6.0 — ALTSEASON RADAR v2 (버그 수정 + 재설계)

[v8.5.2에서 찾은 버그]
1. 월별 점수의 근거 데이터를 coinboss/coinledger/visualcapitalist HTML 을 정규식으로 긁어 만들었음
   → 페이지 구조가 바뀌면 조용히 실패하고 연간 상수(2026 ETH/BTC 0.030, BTC -4% 등 근거 없는 값 포함)로 대체 → "월별 차트"가 사실상 연 단위 계단.
2. 과거표와 현재 점수의 규칙이 서로 다름 (과거: BTC.D/ETH·BTC "수준", 현재: "변화") → 백테스트가 현재 점수를 검증하지 못함.
3. Fed 12개월 변화가 일간 EFFR 12행(=12일) 퍼센트 변화로 계산됨 (점수 기준은 %p 인데 단위도 틀림).
4. ETH/BTC 30일 변화 계산에 BTC "90일 전" 가격을 섞어 사용.
5. 결측 항목이 있으면 분모가 달라져(weight>=50) 시기마다 점수 눈금이 달라짐.
6. M2 를 발표 전 값으로 같은 달에 사용(룩어헤드), 종료일(202609, 30/Sep/2026) 하드코딩 → 다음 달부터 조용히 끊김.
7. BoJ 응답 날짜(yyyymm) 파서 불일치 가능, 단위 검증 없음, 한 지역이라도 빠지면 Global M2 전체가 비어버림.
8. /macro 한 요청이 서브리퀘스트 40여 개 + 배열 find 이중 루프 → 무료 한도(50)·CPU 위험. workers.dev 에서는 Cache API 가 동작하지 않아 캐시도 무효.
9. 2026년 표시가 "현재값"이 아니라 상수로 채워짐.

[한계 — 꼭 읽으세요]
- 과거 BTC.D 월별 실측은 무료 공개 API 가 없음. CoinMarketCap 공개 차트(옵션)를 시도하고, 실패하면 연평균 앵커 보간(근사, 점선 표시).
- ETH/BTC 는 Coinbase 상장(2016-05) 이후만 가능 → 전체 점수는 2016-08 부터, 그 이전은 "거시 3요소" 회색선만 표시.
- 알트 강세 구간(2017-03~2018-01, 2020-10~2021-05, 2024-11~2025-01)은 사후에 정한 참고용이며 점수 계산에는 쓰이지 않음.
- 실제 외부 API 응답으로는 테스트하지 못했고, 합성 데이터 mock 으로 파이프라인·화면을 검증함. 배포 후 화면 하단 "데이터 상태" 줄로 확인.
